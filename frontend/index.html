      Tentang QRGuard & Konsep Reed-Solomon Code

      QRGuard adalah sistem analisis dan pemulihan QR Code berbasis web yang dikembangkan untuk mempelajari penerapan teori pengkodean (Coding Theory), khususnya Reed-Solomon Error Correction pada standar ISO/IEC 18004 (QR Code).

      1. Pengertian & Fungsi Reed-Solomon pada QR Code

      Reed-Solomon Code adalah kode koreksi kesalahan non-biner berbasis blok yang bekerja pada tingkat simbol (codeword berukuran 8-bit / 1 byte). Pada QR Code, algoritma ini menambahkan error correction codewords ke dalam deretan data codewords sehingga scanner tetap dapat memulihkan data asli meskipun sebagian modul QR Code kotor, tergores, atau tertutup.

      2. Struktur Matematis: GF(256) & Polinomial

      • Finite Field GF(28) / GF(256): Seluruh operasi aritmetika codeword dilakukan pada medan hingga Galois berisi 256 elemen menggunakan polinomial primitif standar QR Code: $P(x) = x^8 + x^4 + x^3 + x^2 + 1$.
      • Polynomial Representation: Deretan $k$ data codeword direpresentasikan sebagai polinomial pesan $M(x) = m_{k-1}x^{k-1} + \dots + m_1x + m_0$.
      • Generator Polynomial $G(x)$: Dibentuk dari perkalian faktor linear $G(x) = \prod_{i=0}^{n-k-1} (x - \alpha^i)$, di mana $\alpha$ adalah elemen primitif di $GF(256)$.
      • Encoding & Error Correction: Sisa pembagian polinomial $R(x) = (M(x) \cdot x^{n-k}) \bmod G(x)$ menghasilkan codeword paritas. Saat decoding, sindrom kesalahan dihitung; jika sindrom bernilai nol tidak ada kesalahan, sedangkan jika tidak nol lokasi dan besar kesalahan pada codeword dikoreksi selama jumlah kesalahan tidak melebihi batas $\lfloor (n-k)/2 \rfloor$.

      Klarifikasi Akademis Penting:
      • Persentase kapasitas di atas mengacu pada jumlah codeword yang dapat dikoreksi, bukan persentase luas piksel gambar yang rusak (misalnya, kerusakan kecil tepat pada finder pattern atau format information dapat menggagalkan pembacaan meskipun luasnya kecil).
      • QRGuard memisahkan secara tegas antara analisis kualitas citra (blur, kontras, kecerahan), decoding internal standar QR, dan regenerasi QR Code baru dari payload yang telah berhasil dibaca.
